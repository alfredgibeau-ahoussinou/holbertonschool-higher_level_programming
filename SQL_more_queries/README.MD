# SQL - More queries

## Description
This project covers various SQL topics including creating users, managing privileges, constraints, retrieving data from multiple tables, subqueries, joins, and unions.

## Learning Objectives
By the end of this project, you should be able to:
- Explain how to create a new MySQL user
- Manage privileges for a user to a database or table
- Understand the concept of PRIMARY KEY and FOREIGN KEY
- Use NOT NULL and UNIQUE constraints
- Retrieve data from multiple tables in one request
- Understand subqueries, joins, and unions

## Requirements
- Allowed editors: vi, vim, emacs
- All files will be executed on Ubuntu 20.04 LTS using MySQL 8.0 (version 8.0.25)
- All files should end with a new line
- All SQL queries should have a comment just before (i.e. syntax above)
- All files should start with a comment describing the task
- All SQL keywords should be in uppercase (SELECT, WHERE...)
- A README.md file, at the root of the project folder, is mandatory
- The length of your files will be tested using wc
