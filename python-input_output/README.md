# Python Input/Output

## Description

This project focuses on input/output operations in Python, covering topics such as reading and writing files, JSON serialization and deserialization, and accessing command line parameters. By completing this project, you'll gain a solid understanding of how to work with files and data streams in Python.

## Learning Objectives

By the end of this project, you should be able to:

- Explain why Python programming is considered awesome.
- Open and manipulate files in Python, including reading and writing text.
- Handle file operations such as reading the full content of a file or reading it line by line.
- Understand and utilize JSON serialization and deserialization.
- Access command line parameters within a Python script.

## Requirements

### Python Scripts

- Allowed editors: vi, vim, emacs
- Files will be interpreted/compiled on Ubuntu 20.04 LTS using Python 3.8.5
- All files should end with a new line
- The first line of all files should be exactly `#!/usr/bin/python3`
- A `README.md` file at the root of the project folder is mandatory
- Code should follow PEP 8 guidelines using `pycodestyle` (version 2.7.*)
- All files must be executable
- File lengths will be tested using `wc`

### Python Test Cases

- Allowed editors: vi, vim, emacs
- All files should end with a new line
- Test files should be inside a folder named `tests`
- Test files should have a `.txt` extension
- Tests should be executed using `python3 -m doctest ./tests/*`
- Modules, classes, and functions should have proper documentation
