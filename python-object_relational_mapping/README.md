# Python - Object-relational mapping

## Description
This project focuses on linking databases and Python using Object-Relational Mapping (ORM). The project is divided into two parts. In the first part, the MySQLdb module is used to connect to a MySQL database and execute SQL queries. In the second part, the SQLAlchemy module is used as an ORM to abstract the storage and allow manipulation of objects instead of writing SQL queries.

## Installation
Before starting, please ensure that your MySQL server is version 8.0. You can follow the instructions on how to install MySQL 8.0 in Ubuntu 20.04.

## Learning Objectives
By the end of this project, you should be able to:
- Connect to a MySQL database from a Python script
- Perform SELECT queries on a MySQL table using Python
- Perform INSERT queries on a MySQL table using Python
- Understand the concept of Object-Relational Mapping (ORM)
- Map a Python Class to a MySQL table

## Requirements
- Editors: vi, vim, emacs
- Ubuntu 20.04 LTS
- Python 3.8.5
- MySQLdb version 2.0.x
- SQLAlchemy version 1.4.x
- pycodestyle version 2.7.x

## Usage
1. Clone the repository: `git clone <repository-url>`
2. Change directory to the project folder: `cd <project-folder>`
3. Execute the Python scripts: `python3 <script-name>.py`
